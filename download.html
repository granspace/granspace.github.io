Granspace is distributed as a desktop app (Electron) with the dashboard built in. Pick your platform below — all builds come from the latest release.

Unsigned builds. On macOS, open with right-click → Open (or run xattr -cr /Applications/granspace.app). On Windows, allow it past SmartScreen (More info → Run anyway). Requires git on your PATH (and Docker for compose projects).

After installing

  1. Launch Granspace and point it at the folder(s) where your projects live.
  2. It scans and lists what it finds — mark favorites, set stage/purpose, add tags.
  3. See the first-launch guide to go further.

Updates

The desktop app checks for updates on launch. AppImage and Windows update in place; .deb and unsigned macOS builds show a notification linking back here. You can also trigger a check from Help → Check for updates. See Auto-update.

Extensions

Language/tool support is extensible. Browse the official extensions registry or read Extensions.
