O Granspace dá a cada projeto um pouco de metadado para uma lista longa continuar
escaneável.

## Etapa e propósito

Todo projeto tem uma **etapa** (planejamento, em desenvolvimento, lançado,
pausado, arquivado) e um **propósito** (uso pessoal, só local, quero publicar,
público). Ambos aparecem como badges no card e são filtráveis no painel. Defina-os
no card ou em **Detalhes → Situação**.

## Tags

Tags livres, separadas por vírgula. Elas viram chips coloridos no card e adicionam
um **filtro de tag** ao painel.

Cada tag ganha uma cor automática estável derivada do nome. Para escolher a sua,
abra a aba **Situação** do projeto e clique no quadradinho de cor ao lado de uma
tag (um botão de reset volta à cor automática). As personalizações ficam salvas
localmente.

## Favoritos

Favorite um projeto para fixá-lo no topo (com a ordenação *favoritos primeiro*) e
para trazê-lo aos [menus de abertura rápida]({{ '/pt-br/docs/desktop/quick-open/' | relative_url }})
do desktop (bandeja / dock / jump list).

## Notas

Em **Detalhes → Notas**, anote lembretes rápidos por projeto e fixe os
importantes. As notas são pesquisáveis pela busca global.

## Projetos ausentes

Se uma pasta acompanhada some do disco, o Granspace marca o projeto como **ausente**
(um badge) em vez de descartá-lo — então você não perde seu metadado, notas ou
quadro. Remova-o explicitamente quando terminar, opcionalmente apagando os dados.
