Quando você tem muitos projetos, os grupos (pastas) mantêm o painel arrumado. Um
grupo é uma pasta com nome no painel, no espírito das pastas de apps na tela inicial
do celular: abra para ver os projetos dentro, recolha para deixar a grade curta.

## Criar e preencher grupos

- **Crie um grupo** e dê um nome a ele.
- **Adicione projetos a um grupo** arrastando um card para a pasta, pela própria
  visão do grupo, ou pela barra de ações em massa.
- **Mova um projeto** entre grupos do mesmo jeito; arraste para fora para
  desagrupá-lo.

Projetos que não estão em nenhum grupo ficam soltos no painel ao lado das pastas.

## Organizar

- **Arraste para reordenar** — organize grupos e projetos soltos na ordem que você
  quiser; o layout é salvo e persiste entre reinícios.
- **Filtrar** — o filtro do painel reduz o que aparece; os grupos continuam
  emoldurando os resultados.

## Ações em massa

Selecione vários projetos para agir sobre eles de uma vez:

- **Selecionar tudo** pela barra de ações em massa para pegar tudo que está
  visível.
- Mova a seleção para um grupo, ou aplique uma ação em massa, num passo só.

## Tudo fica local

Grupos são só uma forma de organizar o seu painel — como o resto dos dados do
Granspace, ficam no banco local da sua máquina. Veja
[Organizando]({{ '/pt-br/docs/projects/organizing/' | relative_url }}) para etapa,
propósito, tags e favoritos.
