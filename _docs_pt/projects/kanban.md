Todo projeto tem seu próprio quadro kanban e uma lista de notas.

## O quadro

Abra **Detalhes → Kanban → Ver todas as tarefas** para o quadro completo. Ele tem
colunas (padrão: _A fazer / Fazendo / Feito_) que você pode renomear, adicionar e
remover.

- **Adicione uma tarefa** digitando no campo de uma coluna.
- **Arraste** uma tarefa entre colunas para movê-la.
- **Clique duplo** no título de uma coluna para renomeá-la.

## Detalhes da tarefa

Clique numa tarefa para abrir seu editor, onde você pode definir:

- **descrição**,
- **prioridade** (baixa / média / alta),
- **prazo**,
- **labels**,
- uma **checklist** (com estado de concluído por item).

O card mostra um resumo compacto — prioridade, prazo, progresso da checklist e
labels.

## Notas

Separado das tarefas, **Detalhes → Notas** guarda notas livres que você pode
**fixar**. Tanto tarefas quanto notas são indexadas pela busca global.
