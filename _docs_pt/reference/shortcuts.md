## Globais

| Ação | Atalho |
| --- | --- |
| Focar a busca global | <kbd>/</kbd> ou <kbd>Cmd/Ctrl</kbd>+<kbd>K</kbd> |

## Desktop (aceleradores do menu nativo)

| Ação | Atalho |
| --- | --- |
| Configurações | <kbd>Cmd/Ctrl</kbd>+<kbd>,</kbd> |
| Descobrir projetos | <kbd>Cmd/Ctrl</kbd>+<kbd>D</kbd> |
| Voltar / Avançar | <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>Alt</kbd>+<kbd>→</kbd> |

## Em campos de texto

| Contexto | Tecla |
| --- | --- |
| Mensagem de commit, nova coluna, renomear coluna | <kbd>Enter</kbd> confirma, <kbd>Esc</kbd> cancela |
| Adicionar tarefa / nota / env / tag | <kbd>Enter</kbd> adiciona |
