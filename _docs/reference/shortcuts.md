## Global

| Action | Shortcut |
| --- | --- |
| Focus global search | <kbd>/</kbd> or <kbd>Cmd/Ctrl</kbd>+<kbd>K</kbd> |

## Desktop (native menu accelerators)

| Action | Shortcut |
| --- | --- |
| Settings | <kbd>Cmd/Ctrl</kbd>+<kbd>,</kbd> |
| Discover projects | <kbd>Cmd/Ctrl</kbd>+<kbd>D</kbd> |
| Back / Forward | <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>Alt</kbd>+<kbd>→</kbd> |

## In inputs

| Context | Key |
| --- | --- |
| Commit message, new column, rename column | <kbd>Enter</kbd> to confirm, <kbd>Esc</kbd> to cancel |
| Add task / note / env / tag | <kbd>Enter</kbd> to add |
