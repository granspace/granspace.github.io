Granspace gives each project a bit of metadata so a long list stays scannable.

## Stage & purpose

Every project has a **stage** (planning, in development, launched, paused,
archived) and a **purpose** (personal use, local only, wants to publish, public).
Both show as badges on the card and are filterable on the dashboard. Set them in
the card or under **Details → Situação**.

## Tags

Free-form, comma-separated tags. They render as colored chips on the card and add
a **tag filter** to the dashboard.

Each tag gets a stable auto color derived from its name. To pick your own, open a
project's **Situação** tab and click the swatch next to a tag (a reset button
returns it to the auto color). Overrides are stored locally.

## Favorites

Star a project to pin it to the top (with the *favorites-first* sort) and to
surface it in the desktop [quick-open menus]({{ '/docs/desktop/quick-open/' | relative_url }})
(tray / dock / jump list).

## Notes

Under **Details → Notas**, jot quick notes per project and pin the important ones.
Notes are searchable from the global search.

## Missing projects

If a tracked folder disappears from disk, Granspace marks the project **missing** (a
badge) instead of dropping it — so you don't lose its metadata, notes or board.
Remove it explicitly when you're done, optionally wiping its data.
