devhub

Gerencie os projetos de desenvolvimento espalhados pela sua máquina — descubra, organize, rode e acompanhe, tudo num só lugar.

↓ Baixar Ler a documentação

Roda inteiramente na sua máquina (somente loopback). Disponível agora como app desktop (com o painel embutido). Uma versão web self-hosted e um servidor MCP para agentes de IA estão no roadmap.

O que ele faz

🔍

Descobrir e organizar

Encontra seus projetos em várias pastas e mantém tudo organizado (etapa, propósito, tags, notas).

▶️

Rodar e acompanhar

Inicie/pare projetos e comandos nomeados com logs coloridos ao vivo. Detecção de conflito de porta embutida.

📋

Kanban e notas

Um quadro configurável por projeto, com checklists, prioridades, prazos e notas fixadas.

🔀

Saúde do git

Veja o estado de sincronização de relance e rode pull / push / commit / stash pela interface.

🔑

Secrets criptografados

Variáveis de ambiente por projeto, com secrets criptografados atrás de uma senha-mestra (com chave de recuperação).

🧩

Extensões

Suporte declarativo e instalável para mais linguagens/ferramentas — Node, PHP, Python, Go, Rust, Docker e mais.

Baixar o devhub

🐧

Linux

AppImage (auto-atualizável) ou .deb.
🪟

Windows

Instalador (.exe).
🍎

macOS

Imagem de disco (.dmg).
🤖

Servidor MCP EM BREVE

Deixe agentes de IA gerenciarem seus projetos — no roadmap.

Primeiros passos

  1. Baixe e abra o devhub para o seu sistema.
  2. No primeiro início, aponte para a pasta onde seus projetos ficam — ele os encontra automaticamente.
  3. Organize, rode e acompanhe. Adicione um devhub.json a um projeto para ele se configurar ao ser adicionado.
