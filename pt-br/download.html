O devhub é distribuído como app desktop (Electron) com o painel embutido. Escolha sua plataforma abaixo — todos os builds vêm do último release. (Uma versão web self-hosted e um servidor MCP estão no roadmap.)

Builds não assinados. No macOS, abra com clique-direito → Abrir (ou rode xattr -cr /Applications/devhub.app). No Windows, libere no SmartScreen (Mais informações → Executar assim mesmo). Requer git no PATH (e Docker para projetos compose).
🐧

Linux — AppImage

Portátil e auto-atualizável. chmod +x e rode.
🐧

Linux — .deb

Instalador para Debian / Ubuntu / Pop!_OS.
🪟

Windows

Instalador NSIS (.exe). Atualiza no lugar.
🍎

macOS

Imagem de disco (.dmg).

Depois de instalar

  1. Abra o devhub e aponte para a(s) pasta(s) onde seus projetos ficam.
  2. Ele escaneia e lista o que encontrar — marque favoritos, defina etapa/propósito, adicione tags.
  3. Veja o guia de primeiro início para ir além.

Atualizações

O app desktop verifica atualizações ao iniciar. AppImage e Windows atualizam no lugar; builds .deb e macOS não assinados mostram uma notificação com link para cá. Você também pode verificar em Ajuda → Verificar atualizações. Veja Auto-update.

Extensões

O suporte a linguagens/ferramentas é extensível. Navegue no registro oficial de extensões ou leia Extensões.
